## 三、使用方式

### 1. 图片引用（推荐，最简单、无 id 冲突）

```html
<img src="assets/logo.svg" alt="河小智" width="36" height="36">
<img src="assets/mascot.svg" alt="河小智吉祥物" width="620" height="560">
<img src="assets/activity-ai.svg" alt="AI 创客马拉松活动封面" class="card-cover">
```

```python
# Streamlit
st.image("assets/logo.svg", width=36)
st.image("assets/mascot.svg", width=380)
st.image("assets/activity-ai.svg", use_container_width=True)
```

### 2. 活动卡片封面

16:9 封面为满幅深色画面，圆角建议交给 CSS 裁切，图像本身不画圆角：

```css
.card-cover {
  display: block;
  width: 100%;
  height: auto;
  border-radius: 16px;
  overflow: hidden;
}
```

叠加白色文字时，请使用封面底部已内置的**深色渐变安全区**（约底部 210–240px）：

- 标题建议距底 24–96px、距左 ≥24px，单行或两行以内；
- 小字号 meta 文字放在更靠下的位置（该处渐变最深）；
- 若标题较长，优先落在左下 2/3 宽度内（`activity-lecture.svg` 的书本、`activity-run.svg` 的奔跑者位于画面中右部，左下区域干净）。

### 3. 内联 SVG（可选）

每个文件的内部 id 均带文件前缀，可安全地把多个 SVG 内联进同一页面而不冲突：

| 文件 | id 前缀 |
| --- | --- |
| logo.svg | `lg-` |
| favicon.svg | `fv-` |
| mascot.svg | `ms-` |
| activity-ai.svg | `ai-` |
| activity-music.svg | `mu-` |
| activity-lecture.svg | `le-` |
| activity-run.svg | `ru-` |

## 四、技术规范与自检结果

- 手写 SVG / 合法 XML（UTF-8，含 XML 声明）；`viewBox` 与 `width`/`height` 一致。
- 根节点带 `role="img"` 与 `aria-labelledby`，指向首个 `<title>` 与其后 `<desc>`。
- 无 `<text>` / `<image>` / `<script>` / 外部字体 / base64 / 外链；渐变、滤镜、剪贴路径、遮罩均为内联定义。
- **格式验证**：用 Python 标准库 `xml.etree.ElementTree` 逐个解析 —— 7/7 通过；
  所有 `url(#id)` 与 `aria-labelledby` 引用均可解析；跨文件 id 无重复（已加文件前缀）。
- **渲染自查**：用自建轻量光栅化脚本按 2× 超采样渲染四张封面、吉祥物、Logo 并逐张目检；
  另导出 logo 36px / 24px 与 favicon 16px / 32px，确认小尺寸清晰。
- **白色文字对比度（底部安全区实测均值）**：
  `activity-ai` ≈ 7.2:1、`activity-music` ≈ 5.9:1、`activity-lecture` ≈ 6.1:1、`activity-run` ≈ 7.3:1。
- **透明背景**：`mascot.svg` 四角 alpha = 0（不铺底，可直接叠在浅底或白卡片上）。
- **体积**：约 2.5–12.6 KB / 个，可直接进入前端仓库。

## 五、修改建议

- 换色时统一改 `<defs>` 中对应渐变的 `stop-color`；注意保留各文件 id 前缀。
- 文案不要画进 SVG（本目录所有 SVG 均无文字），交给 HTML / Streamlit 渲染，便于维护与多语言。
- 需要浅色版卡片时，建议在页面侧给封面叠加 CSS 遮罩，而不是重做图像。
