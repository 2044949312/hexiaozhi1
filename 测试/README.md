# 河小智 · 模拟测试版

这是一个**完全独立、纯静态**的「河小智」模拟版本，放在 `测试` 文件夹中，用于在没有服务器、没有网络、没有 API Key 的情况下直接体验产品的主要功能。

它与正式版共用同一套页面、品牌视觉和交互思路，但数据全部在浏览器本地模拟，**不会连接任何后端，也不会调用任何大模型 API**。

## 怎么打开

### 方式一：双击 HTML

直接双击本文件夹里的 **`index.html`**，用 Chrome / Edge 打开即可。

### 方式二：双击启动脚本

双击 **`打开测试版.bat`**，会使用系统默认浏览器打开。

> 不需要安装 Python、Streamlit 或其他依赖，也不需要启动 `http://localhost:8501`。
>
> `index.html` 和 `assets` 文件夹必须放在一起；如果只把 `index.html` 单独复制走，页面样式和脚本会丢失。

## 已实现的功能

- **登录 / 注册 / 找回密码**：本地账号号按注册顺序生成（`HXZ0001`、`HXZ0002`……），支持用户名或账号号登录，支持密保问题重置密码。
- **首页**：动态问候、AI 提问入口、核心功能入口、今日待办、通知公告、快捷服务、成长横幅。
- **智能问答**：本地知识库 + 关键词 / 2-gram 匹配，支持推荐问题、相关追问、来源标注；可检索本地知识库、查看高频问题、通知公告、资助政策、办事流程，并上传文本资料参与检索。
- **办事流程**：输入「校园卡丢了」等自然语言需求，本地识别流程，展示置信度、推荐流程与备选流程，生成可勾选的材料 / 步骤清单，可一键加入个人待办。
- **校园活动**：官方活动分类、详情、报名 / 取消报名；「我的活动」支持查看已报名、创建活动、删除自建活动、活动任务看板。
- **个人事务中心**：待办增删改查与完成状态、课表、一卡通余额、模拟宿舍报修、数据概览。
- **成长档案**：成长值、能力画像、徽章、目标、时间线、待办完成情况和活动参与统计。
- **本地资料上传**：支持 `.txt / .md / .csv / .json / .log / .html` 文本文件，最多 5 份，单份不超过 400KB，只在当前浏览器中读取。

## 数据与隐私

- 所有账号、待办、报名、活动任务、报修单、办事计划和问答记录都保存在浏览器的 **localStorage** 中。
- 页面不发起 `fetch` / `XMLHttpRequest` / WebSocket 请求，不加载 CDN、外部字体或远程图片；图标为内联 SVG，封面和吉祥物为本地 SVG。
- 上传的文件通过浏览器 `FileReader` 在本地读取，不会发送到任何服务器。
- 清除浏览器站点数据、换一个浏览器或使用无痕模式，都会导致本地数据不可用；可以在页脚点击「重置本地数据」重新开始。
- 密码和密保答案只做本地演示哈希，**不具备真实安全强度，请勿使用真实校园密码或真实隐私信息**。
- 本版本是产品原型和演示，不是河南大学官方系统，页面内的政策、金额、电话和时间请以学校当年正式通知为准。

## 与正式版的区别

| 项目 | 正式版 | 本模拟版 |
| --- | --- | --- |
| 运行方式 | Python + Streamlit 本地服务 | 双击 HTML，纯静态 |
| 数据存储 | SQLite / 服务端会话 | 浏览器 localStorage |
| 智能问答 | 本地检索 + 可选大模型 API | 仅本地检索，不调用 API |
| 学校系统 | 可继续接入 | 全部为演示数据 |
| 依赖 | Python、Streamlit | 只需要浏览器 |

## 常见问题

**打开后是空白页？**  
确认 `assets` 文件夹与 `index.html` 在同一目录，并使用较新的 Chrome / Edge。也可以在浏览器控制台查看是否有脚本报错。

**登录后刷新，数据还在吗？**  
在同一个浏览器、同一个文件路径下会保留。移动文件夹、换浏览器或清理站点数据后会重新开始。

**为什么问答回答比较固定？**  
模拟版没有大模型，回答来自 `assets/data.js` 中的本地知识库和关键词匹配，因此适合演示流程，不适合开放式聊天。

**会偷偷联网吗？**  
不会。除了浏览器自身的行为外，页面没有网络请求代码；可断网后双击打开验证。
