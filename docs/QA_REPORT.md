### 交互流

| 流程 | 结果 |
| --- | --- |
| 首页 AI 输入 → 问答页 | 成功，URL 带 `page=qa&q=...`，答案包含「校园卡丢失补办指南」 |
| 首页待办点击 | 完成数 1 → 2，进度条更新 |

## 四、已知边界

1. 本期验收以首页为准；四大功能页面为可替换的起步骨架，后续由项目继续补充。
2. 待办完成状态、活动报名状态保存在当前 Streamlit 会话；整页刷新/新会话会回到演示初始状态。
3. 所有数据均为黑客松演示数据，不连接学校真实业务系统。
4. AI 问答为本地知识库检索演示，未调用外部大模型；回答中已标注制度来源。
